# Core: User (Resource)

Manages a DSM local user. The initial password is write-only (`password_wo`) and is never stored in state; bump `password_wo_version` to rotate.

## Example Usage

```terraform
terraform {
  required_version = ">= 1.11.0"

  required_providers {
    synology = {
      source = "synology-community/synology"
    }
  }
}

# password_wo is write-only: never stored in state. Bump password_wo_version to rotate.
resource "synology_core_user" "svc" {
  name                = "tofu-svc"
  password_wo         = var.initial_password
  password_wo_version = 1
  description         = "OpenTofu-managed service account"
  email               = "ops@example.com"
  groups              = ["users"]
}

variable "initial_password" {
  type      = string
  sensitive = true
}
```

## Schema

### Required

- `name` (String) Username. Changing this forces replacement.

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `cannot_change_password` (Boolean) When true, the user cannot change their own password.
- `description` (String) User description.
- `email` (String) User email address.
- `expire` (String) Account expiry setting as accepted by DSM (`never`, a date, etc.).
- `groups` (Set of String) Group names the user belongs to. Membership is declared only on the user resource (not on `synology_core_group`).
- `password_never_expire` (Boolean) When true, the password never expires.
- `password_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) Initial password (or rotation value). Never stored in state. Requires OpenTofu >= 1.11 write-only attribute support.
- `password_wo_version` (Number) Increment to apply a new `password_wo` value (rotation). OpenTofu cannot diff write-only attributes, so this is the only rotation signal.

### Read-Only

- `uid` (Number) Numeric user id assigned by DSM.

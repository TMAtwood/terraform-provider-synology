# Core: Share (Resource)

Manages a DSM shared folder. Name and volume force replacement; description, visibility, recycle bin, and compression update in place via `SYNO.Core.Share` method `set`.

## Example Usage

```terraform
resource "synology_core_share" "scratch" {
  name     = "tofu-scratch"
  vol_path = "/volume1"
  desc     = "Scratch share managed by OpenTofu"

  enable_recycle_bin     = true
  recycle_bin_admin_only = true
  enable_share_compress  = false
  hidden                 = false
}
```

## Schema

### Required

- `name` (String) Share name. Changing this forces replacement (rename is not implemented).
- `vol_path` (String) Volume path, e.g. `/volume1`. Changing this forces replacement — DSM does not move share data between volumes in place.

### Optional

- `desc` (String) Share description.
- `enable_recycle_bin` (Boolean) Enable the share recycle bin.
- `enable_share_compress` (Boolean) Enable Btrfs compression for the share when supported.
- `hidden` (Boolean) Hide the share from browse lists.
- `recycle_bin_admin_only` (Boolean) Restrict recycle bin access to administrators.

### Read-Only

- `uuid` (String) DSM-assigned share UUID.

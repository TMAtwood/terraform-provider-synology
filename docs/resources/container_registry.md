# Container: Registry (Resource)

Manages a Container Manager registry entry. DSM exposes create and delete for third-party registries; `set` rejects the documented parameter shapes on the tested DSM, so every attribute forces replacement.

## Example Usage

```terraform
resource "synology_container_registry" "ghcr" {
  name             = "ghcr"
  url              = "https://ghcr.io"
  enable_trust_ssc = false
}
```
